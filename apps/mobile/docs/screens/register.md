# 新規登録

- 実装: [`app/register.tsx`](../../app/register.tsx)
- 役割: ニックネーム、メール、パスワード、メニューと店員回答の公開選択、利用規約の確認を受け付ける。
- 公開選択: `Agree` / `Do not agree` のどちらかを必須にする。これは利用規約への同意とは別の選択。
- 規約: [`/terms`](terms.md) へのリンクと必須チェックを表示する。②で同意して来た場合はチェック済み。未チェックなら送信ボタンを押せず、送信処理でも拒否する。
- API設定時: [`src/api/auth.ts`](../features/auth.md) の `POST /auth/register` を呼び、成功したら `/profiles/setup?created=1` に進む。
- API未設定時: 入力だけ検証し、アカウントを作成しない。プレビューであることを画面に表示する。
- 未実装: 利用規約同意の日時・版をサーバーに記録するAPIはない。現在のチェックは画面内の送信条件であり、永続的な同意記録ではない。
