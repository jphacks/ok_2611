# 新規登録

- 実装: [`app/register.tsx`](../../app/register.tsx)
- 役割: ニックネーム、メール、パスワードを入力してアカウントを作成する。規約同意は直前の②で済ませる。
- 公開同意: 独立した選択欄は置かない。利用規約に公開条件を明記し、規約同意後の登録APIには `publish_consent: true` を送る。
- 規約: この画面に重複したチェックやリンクは置かない。②を経ずに直接開いた場合は入力フォームを出さず、[利用規約のある②](onboarding.md)へ戻す。
- API設定時: [`src/api/auth.ts`](../features/auth.md) の `POST /auth/register` を呼び、成功したら `/profiles/setup?created=1` に進む。
- API未設定時: 入力だけ検証し、アカウントを作らずに⑤の選択プレビューへ進む。画面にプレビューであることを表示する。
- `Back` はブラウザー履歴に関係なく利用開始前の説明画面 `/onboarding` に戻る。
- 未実装: 利用規約同意の日時・版をサーバーに記録するAPIはない。現在のチェックは画面内の送信条件であり、永続的な同意記録ではない。
